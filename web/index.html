Checking browser storage…

Choose the Dune CD image (.iso, or a .zip containing it), or the two files DNCDPRG.EXE and DUNE.DAT. Files are copied into this browser's private storage and never uploaded. The game itself is not included — see installation.

Remastered soundtrack (optional)

    Stéphane Picq, the game's composer, released a remaster of the original music: Dune Spice Opera 2024 remaster. It is copyrighted: buy it on Bandcamp, download the MP3 ZIP, and import it here. The game then plays the remastered recordings instead of its FM music. The files stay in this browser.
